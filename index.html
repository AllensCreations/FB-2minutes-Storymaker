FB 2minutes Storymaker

Automated Storytelling Engine for Picture-Book Motion Videos

Project Status

✓ Speech-Cue Align Engine ▢ Scene Duration Director ▢ Visual Choreography Core ▢ Final Master Video Exporter

How to Use

This project is primarily a command-line tool. Follow these steps to run the storytelling engine:

# 1. Check your assets are ready python main.py # 2. Test the Speech-Cue Align Engine (first implemented module) python -m src.align_engine.align_engine \\ --audio assets/voice-over/narration.mp3 \\ --script assets/scripts/story.txt \\ --output assets/processed/alignment.txt # 3. View the alignment results cat assets/processed/alignment.txt

Alternative: Using Makefile

# Install development dependencies make dev # Run the asset check make run # Test the align engine python -m src.align_engine.align_engine --audio assets/voice-over/narration.mp3 --script assets/scripts/story.txt --output assets/processed/alignment.txt
